# Специфікація: поле, рендеринг і базовий AI  
## 1. Модель поля  
Використати axial-координати шестикутної сітки (q, r).  
```
type Axial = { q: number; r: number };

const BOARD_RADIUS = 4; // 1 + 3 × 4 × 5 = 61 клітинка

function isOnBoard({ q, r }: Axial): boolean {
  return Math.max(Math.abs(q), Math.abs(r), Math.abs(q + r)) <= BOARD_RADIUS;
}
```
Напрямки сусідніх гексів:  
```
const DIRECTIONS: Axial[] = [
  { q: 1, r: 0 },
  { q: 1, r: -1 },
  { q: 0, r: -1 },
  { q: -1, r: 0 },
  { q: -1, r: 1 },
  { q: 0, r: 1 },
];
```
Перетворення в екранні координати для pointy-top гексів:  
```
function axialToPixel(cell: Axial, radiusPx: number) {
  return {
    x: originX + Math.sqrt(3) * radiusPx * (cell.q + cell.r / 2),
    y: originY + 1.5 * radiusPx * cell.r,
  };
}
```
radiusPx — відстань від центра гекса до вершини. Усі PNG-тайли мають центр полотна як точку прив’язки.  
## 2. Спеціальні клітинки  

| Тип | Координати | Правило |
| ----------------- | ------------------------ | --------------------------------- |
| Трон | (0, 0) | Доступний для зупинки лише Королю |
| Виходи | (0, -4), (4, 0), (-4, 4) | Доступні для зупинки лише Королю |
| Кути заколотників | (-4, 0), (0, 4), (4, -4) | Стартові зони нападників |
  
Стартові позиції:  
```
const king = { q: 0, r: 0 };

const guards = [
  { q: 1, r: 0 },
  { q: 1, r: -1 },
  { q: 0, r: 1 },
  { q: -1, r: 0 },
  { q: -1, r: 1 },
];
// Гекс (0, -1) лишається відкритим як напрямок прориву.

const attackers = [
  { q: -4, r: 0 }, { q: -4, r: 1 }, { q: -3, r: -1 },
  { q: 0, r: 4 },  { q: -1, r: 4 }, { q: 1, r: 3 },
  { q: 4, r: -4 }, { q: 4, r: -3 }, { q: 3, r: -4 },
];
```
## 3. Рендеринг поля  
Порядок шарів:  
1. khazad-dum-board-background-large-hex-v1.png  
2. Базові гекси: khazad-dum-hex-floor-v1.png  
3. Спеціальні гекси: трон або відкриті/закриті ворота  
4. Тонкі окантовки зовнішнього краю поля  
5. Токени  
6. UI: підсвічування ходу, доступні клітинки, анімації  
Для фонової плити використати один великий спрайт у центрі поля. Її потрібно повернути на 90°, щоб широкий бік відповідав формі поля з 61 гекса.  
**Тайли**  
```
const assets = {
  floor: "khazad-dum-hex-floor-v1.png",
  throne: "khazad-dum-hex-throne-v1.png",
  exitOpen: "khazad-dum-hex-exit-open-v2-inward.png",
  exitClosed: "khazad-dum-hex-exit-closed-v1.png", // майбутній asset
  edge: "khazad-dum-hex-edge-thin-trapezoid-v1.png",
};
```
Ворота мають базову орієнтацію для виходу (0, -4). Для інших виходів:  
```
const exits = [
  { cell: { q: 0, r: -4 }, rotation: 0 },
  { cell: { q: 4, r: 0 }, rotation: 120 },
  { cell: { q: -4, r: 4 }, rotation: 240 },
];
```
Створки у відкритому тайлі завжди спрямовані всередину гекса. Стан open або closed змінює лише використаний спрайт; координата й поворот лишаються тими самими.  
**Окантовка**  
Тонкий трапецієподібний спрайт бортика застосовувати лише до зовнішніх граней поля:  
```
function isExposedEdge(cell: Axial, direction: Axial) {
  return !isOnBoard({
    q: cell.q + direction.q,
    r: cell.r + direction.r,
  });
}
```
Для кожної зовнішньої грані:  
* розмістити edge у середині грані;  
* повернути на кут відповідного напрямку;  
* намалювати поверх базового тайла, але під токенами;  
* не малювати бортики на спільних внутрішніх гранях.  
Це не створює подвійних стін між сусідніми клітинками. Якщо пізніше знадобиться рельєф кожної клітинки, варто створити окремий повний hex-overlay із вбудованим bevel, а не дублювати боковий бортик шість разів.  
## 4. Ігровий рушій  
Рушій не повинен залежати від графіки. Стан гри зберігається окремо від спрайтів:  
```
type PieceType = "king" | "guard" | "attacker";
type Side = "clan" | "rebels";

type GameState = {
  pieces: Map<string, { type: PieceType; side: Side; cell: Axial }>;
  currentSide: Side;
  captured: Record<Side, PieceType[]>;
  turnNumber: number;
  dice?: [number, number];
};
```
Один рух складається з:  
1. кидка двох кубиків;  
2. генерації допустимих дій для кожного кубика;  
3. застосування дії;  
4. перевірки захоплень після кожного переміщення;  
5. перевірки перемоги або нічиєї.  
Для гекса з числом N генеруються прямі ходи по шести напрямках довжиною від 1 до N. Фігура не перестрибує інші фігури. Гвардієць і нападник не можуть завершити рух на Троні чи Виході, але можуть пройти крізь них.
